# AI-Generated Phishing Email Classifier

## Project Overview
A machine learning model that classifies emails into 3 categories:
- Legitimate: Normal everyday emails
- Traditional Phishing: Obvious phishing with aggressive language
- AI-Generated Phishing: Sophisticated realistic phishing emails generated by AI

## Model Performance
- Overall Accuracy: 98%
- AI-Generated Phishing F1-Score: 1.00
- Traditional Phishing F1-Score: 0.98
- Legitimate F1-Score: 0.98

## Files
- lr_final.pkl: Logistic Regression model
- svm_final.pkl: Support Vector Machine model
- tfidf_final2.pkl: TF-IDF Vectorizer
- predict.py: Run predictions on new emails

## How to Use
from predict import predict_email
label, confidence = predict_email("Your email text here")
print(label, confidence)

## Datasets Used
1. Phishing Legitimate Dataset KD 10000
2. Enron Fraud Labeled Dataset
3. Spam Emails Dataset
4. Synthetic AI-Generated Phishing Emails using distilgpt2

## Tech Stack
- Python, Scikit-learn, TF-IDF Vectorizer
- Logistic Regression + SVM Ensemble
